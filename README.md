## 本次发布包含哪些修改

自GitHub上一版B13.4.25以来：
- **景别与正向表达**：中景／全景可表达身体互动、人物关系和环境，不要求证明近景不可替代。正文描写实际画面与表演，删除冗余防错尾句；剧情拒绝、原话中的否定及必要输出约束保留。
- **按需详略**：普通镜头写清楚即可，关键表演与复杂动作按需展开。取消每镜两三倍扩写导向和不到两倍的提醒，清除普通镜头也必须完整展开表演链的冲突。
- 同步主流程、导演入口、编译模板说明、详略参考、表演引擎、质量门及示例。描述量统计仅作观察，对照稿只检查镜号／时间可比性。未修改真实@算法。

不新增字数、句数、微动作数量、景别比例或镜长门槛。原话、连续性、七板块、导演指导、画面＋表演、自然时长、镜数软参考、真实@、资产复用、480P／9:16／有声音等标准及视频生成前冻结保持。动画、独立首集、旧LOCK及历史画布未改；未生成媒体。

本完整包仅主流程与默认真人导演更新，其余八个随包Skill与B13.4.25逐文件一致。旧927流程和旧项目模板不打包。源代码位于完整Release附件内，不在GitHub自动Source code内。
