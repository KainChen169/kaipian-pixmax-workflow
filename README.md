## 默认工作流程

全剧从第1集至末集全部纳入；对账已有成果，复用合格项、补齐缺项，不重复制作。
锁定正式剧本与当集提示词 → 按原授权补资产并验收 → 分集紧凑画布及完整剧本／整集提示词阅读附件 → 未运行视频节点 → 完整执行稿、有序连线与真实@ → 全文回读及生成前检查 → “已准备，未生成”或真实缺项。

新团队项目成员分配前置、公共资产跨Agent认领、保留来源日期／S前缀、图片失败有界恢复、小数秒参数向上取整、参考输入动态schema和原文锁均不变。
站位底稿是文字附件，不生成站位图、不进入参考输入。导演规则只影响新写／获准重编稿，不批量重写历史LOCK。
