# 工作流B13.4.7｜紧凑自主准备版｜2026-10-11

相比B13.4.6，本次仅合并用户确认的两项规则更新，默认导演仍B13.4.2。

## 1. 紧凑画布排布

紧凑画布排布：资产、补图结果和待生成视频按收起卡片实际边界加小留白排齐，节点／标题不重叠；卡片约200高可参考280行距（约80净空），不是固定值。不沿用720／1250等宽松间距，不永久给全部展开面板留空；操作时只展开当前面板，先收起其他面板／平移，真实遮挡才局部让位。保留分区、剧情顺序、UUID、完整提示词、参数、有序输入和真实@／连线。工具宽松默认坐标只作草稿，粘贴前依规范调整位置，不宣称已有一键自动排版；不批量整理历史画布。

删除入口与参考中要求按所有完整展开面板预留大行距的冲突表述。修改主SKILL、AGENTS、canvas-layout、optimized-execution、script-driven-workflow、bounded-retries-and-live-canvas与closeup-supplements-10s。约280指行起点差而非净空，尺寸变化须调整；不改脚本坐标算法，粘贴前遵守布局规范。

## 2. 自主排障与结束知会

授权内自主处理：一般执行问题先查证据，自行选择最合适的可行方案、处理并核验，不为常规取舍停下来让用户选；优先复用合格结果、已验证官方路径和最小可恢复修改。未知任务先对账不重发，只暂停真实依赖，独立工作继续。结束简述问题、判断依据、处理、真实结果与剩余项，过程仍给简短进度。实质改剧情／标准／模型、突破范围／预算／次数、不可恢复删除、权限／安全变更及真实工具审批仍按原规则确认，不绕过检测、不恢复冻结阶段。

修改主SKILL、AGENTS及bounded-retries-and-live-canvas；人物检测失败先查同角色同状态可用资产及原图片授权恢复，不默认等用户提供替换图。ACTIVE与图片验收仍保留。

## 保留与验证边界

其他8个Skill、导演、所有脚本和CLI运行时保持B13.4.6包版本不变；保留2.5动态参考容量（当前快照图片30、多媒体总50，不是50张图片）、团队成员前置、小数向上取整、图片失败恢复、共享资产防重和原文锁。两个927旧流程与旧模板不打包。视频生成／补修、超分、剪辑台、自动下载／导出仍冻结。

规则与文档更新不证明已实现自动排版或自动排障程序。本次未收费生成、未改历史画布；离线校验与隔离安装结果见checks/离线校验结果.json，不冒充目标机在线制作验证。Skill Creator通用quick_validate缺PyYAML未运行，原frontmatter未改。每次交付继续附可复制Agent更新指令，包内为导入时复制给Agent.txt。
