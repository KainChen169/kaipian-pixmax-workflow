# 工作流B13.4.5｜团队项目成员前置｜2026-10-10

## 本次改动

1. 新建TK短剧团队项目成功取得真实UUID后，第一时间在“成员分配”中加入当前TK短剧团队全部成员，保存回读核对无遗漏，之后才创建画布／导入资产／配置节点。
2. 读取正确团队的实时完整名单（含分页），按真实成员ID去重，只补未加入者。已有成员和权限保留，不取单页或历史名单，不把整个企业名单当TK团队，不邀请外部人员或授予管理员／所有者。
3. 主Agent唯一负责，分集Agent复用项目UUID和核验结果；保存超时先对账，权限／名单受阻如实说明，不重建项目，暂停该项目后续远端制作，本地规划可继续。
4. 仅适用于本次新建及其中断续跑项目，不批量修改历史项目，也不后台持续同步。新增 `references/team-project-members.md`，同步主SKILL、AGENTS、统一编排和日常执行顺序入口。
5. 这是Agent执行规范，未增加平台成员分配API或自动脚本。旧`prepare`若会直接创建画布／导入资产，在团队项目场景不能跳过此步骤整链运行；应先创建／复用项目并核验成员，再进入后续准备。
6. 可复制Agent更新指令继续放入包内 `导入时复制给Agent.txt`、发布说明和GitHub更新文档。

小数时长向上取整与配套校验、图片失败主动恢复和三行缺项说明、对白漏检与旧案例修复均保留。导演篇幅、镜数软参考、自然分段、空间继承、微动作、景别自由度、闪回及对白标准不变。视频生成／补修、超分、剪辑台汇总和自动下载导出继续冻结，默认停在生成前。两个927旧流程、旧项目模板和账号／实际成员名单／私人项目资料均不打包。
